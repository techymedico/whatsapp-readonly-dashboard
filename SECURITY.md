# Security

Never submit real phone numbers, student names, receipts, tokens or environment files in public issues. Report security defects privately through the repository's security reporting feature if enabled; otherwise contact the maintainer without including exploit secrets.

This preview uses one shared administrator password, in-memory sessions, strict cookies and login throttling. Use HTTPS and an access-controlled host. It has no WhatsApp sending client. Production rollout requires review of the Firebase capture adapter, account allowlists, private media export and retention policy.
